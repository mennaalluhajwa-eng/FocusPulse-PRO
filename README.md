#  FocusPulse PRO - Glassmorphic Productivity Dashboard

A modern, interactive, glassmorphic habit tracking dashboard built with Vanilla JavaScript, HTML5, and CSS3.

##  Key Features
-  **Live Analytics:** Real-time data visualization via Chart.js (Radar, Bar, Heatmap).
- ⏱ **Focus Timer:** Interactive 3D Flip Clock & Pomodoro timer with audio-visual feedback.
-  **Habit Matrix:** Dynamic daily habit tracking with multi-stage progress.
-  **Weather & Quotes:** Live weather widget via Open-Meteo API and daily motivation.
-  **Data Export:** Export habits & progress to CSV or JSON formats.

##  Built With
- **HTML5 & CSS3** (Glassmorphism UI, Custom CSS Variables, 3D CSS Animations)
- **Vanilla JavaScript (ES6+)**
- **Chart.js** (Data Visualization)
- **Web Audio API** (Pure Generated Sound Synthesizer)
